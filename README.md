# EDA-Analysis-Graduation-Employment-Outcomes

Performed exploratory data analysis on graduate employment data for a consortium of universities using Excel. Applied PivotTables, lookup functions, summary statistics, and conditional formatting to uncover trends in salaries, employment rates, and underemployment across majors, supporting data-driven recommendations for academic program evaluation.
